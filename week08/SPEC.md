주차 요금 계산기 명세서
1. 프로그램 목적

입차 시각과 출차 시각을 입력하면 주차 시간과 요금을 계산하고, 주차 내역 목록과 오늘 받은 요금의 합계를 보여 주는 창 하나짜리 프로그램을 만든다.

2. 입력 규칙
시각은 24시간제 HH:MM 형식으로 입력한다.
올바른 입력 예시는 09:30, 18:05, 00:15이다.
시는 00~23, 분은 00~59 범위여야 한다.
빈 입력은 허용하지 않는다.
9:30, 24:00, 12:60 등 잘못된 입력은 오류로 처리한다.
출차 시각은 입차 시각보다 반드시 늦어야 한다.
자정을 넘기는 주차는 지원하지 않는다.
3. 요금 계산 규칙
주차 시간은 출차 시각에서 입차 시각을 뺀 분 단위 시간이다.
주차 시간이 30분 이하이면 무료이다.
30분 초과분은 10분 단위로 올림 계산한다.
10분마다 500원을 부과한다.
하루 최대 요금은 20,000원이다.
금액은 천 단위마다 쉼표를 넣어 표시한다.
요금 계산 예시
주차 시간	계산	요금
20분	무료	0원
30분	무료	0원
31분	초과 1분 → 10분 단위 1개	500원
40분	초과 10분 → 10분 단위 1개	500원
41분	초과 11분 → 10분 단위 2개	1,000원
60분	초과 30분 → 10분 단위 3개	1,500원
430분	계산 요금이 상한에 도달	20,000원
4. 화면 규칙
입차 시각과 출차 시각을 입력하는 칸을 제공한다.
계산 버튼을 누르면 입력을 검증하고 요금을 계산한다.
계산에 성공하면 내역을 목록에 추가한다.
목록에는 입차 시각, 출차 시각, 주차 시간, 요금을 표시한다.
목록의 각 내역에는 삭제 버튼을 제공한다.
내역을 삭제하면 총요금을 다시 계산한다.
총요금은 현재 목록에 있는 요금의 합계이다.
목록이 비어 있으면 총요금은 0원으로 표시한다.
잘못된 입력은 오류 메시지로 안내한다.

6. 오류 테스트
입력	예상 결과
입차 시각이 비어 있음	오류 메시지
출차 시각이 비어 있음	오류 메시지
9:30	형식 오류
24:00	시각 범위 오류
12:60	시각 범위 오류
입차 09:00, 출차 09:00	출차 시각 오류
입차 10:00, 출차 09:00	출차 시각 오류
입차 23:00, 출차 01:00	자정 넘김 오류
7. 구현 및 테스트 환경
프로그래밍 언어: Python 3
GUI: Tkinter
계산 로직은 화면 코드와 분리한다.
테스트는 GUI를 실행하지 않고 수행할 수 있어야 한다.
테스트 파일을 실행하면 통과한 테스트 수와 실패한 테스트 수를 출력한다.
8. 제출 파일
SPEC.md: 프로그램 명세서와 테스트 표
calculator.py: 주차 시간 및 요금 계산 로직
test_calculator.py: 자동 테스트
app.py: GUI 화면

첫 번째 커밋에는 SPEC.md만 포함한다. 전체 커밋 수는 3개 이상이어야 한다.
